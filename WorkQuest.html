Quest 0 — First Blood (Your First Dollar)

Project tutorial first. Goal: ship one tiny paid deliverable in 7 days. Not a startup — a single useful thing someone pays $5–$29 for.

DAY 1 — Pick the problem - List 5 tiny annoyances you or people you know have. - Pick one solvable in ~4 hours of work. - Validate: ask 3 people "would you pay $10 for X?" If 2+ say yes, proceed. DAY 2 — Build the MVP - Build the smallest version that delivers the promised value. - No polish yet. Working > pretty. DAY 3 — Package - README / instructions / demo (screenshot or 30s video). - Set price: $5 (impulse), $15 (fair), $29 (premium). Start low. DAY 4 — List - Gumroad (digital) OR Fiverr (service) OR Etsy (template). - Title = outcome, not feature. "Save 2 hours cleaning CSVs" not "CSV cleaner". DAY 5 — Share (value-first, no spam) - Post in 3 communities where your buyer lives (Discord, Reddit, X). - Lead with the problem + free tip; link at the end. DAY 6 — Iterate - If 0 buyers: talk to 3 non-buyers, find the objection, fix. - If 1+ buyers: ask for a testimonial + what almost stopped them. DAY 7 — Deliver & plan - Deliver, refund policy honored, thank-you note. - Decide: scale this, or run Quest 0 again on a new idea.

Rules of Quest 0

  • Do NOT build for 3 weeks before showing anyone. Ship in 7 days max.
  • Do NOT add features nobody asked for.
  • Do NOT fake reviews or testimonials. Honor -20 per lie.
  • Do respond to every buyer within 24h.

Code of Honor

Break these and your Honor drops. Low Honor = no real reputation, no repeat buyers.

  • No scams, no fake reviews, no fabricated testimonials. Ever.
  • No plagiarized code/content. Credit sources; license properly.
  • No exploitative labor — don't resell underpaid work as your own premium service.
  • No deceptive claims — don't promise results you can't deliver.
  • Transparent pricing — no hidden fees, no dark patterns.
  • Honor refunds — if it didn't work, refund. Reputation > one sale.
  • Pay your taxes — track income from day one.
  • Protect user data — especially if you handle any customer info (see secure-local-webapp principles).
  • Don't spam communities — value first, link last.
