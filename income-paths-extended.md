# Income Paths — Extended (10 more, ranked)

Beyond the existing 6 (Premium Product, Affiliate Engine, Productized Service, Licensing, Audience Asset, Micro-SaaS). All ethical, solo-executable. Estimates marked (est.). Effort 1-5 (1=easiest). Ceiling = rough monthly upper (est., varies wildly).

Ranking: effort→ceiling ratio, speed to first $, honesty. #1 best.

---

## 1. AI Eval / Data Labeling Gigs (effort 1, ceiling ~$500–$1,500/mo, first $ in days)
- One-line: Get paid to rate/review AI outputs on platforms like Outlier, Remotasks, Toloka, Scale AI.
- Steps: Sign up at 2-3 platforms; pass qualification tests (1-2 hrs); work 5-10 hrs/wk; graduate to higher-paying eval tasks as rating rises.
- Risk: Low. Pay is low; treat as runway, not career.
- Best for: Analyst.
- Honor: Don't fabricate qualifications; don't submit careless labels.

## 2. Open-Source Bounties (effort 2, ceiling ~$100–$5,000/bounty, first $ in days-weeks)
- One-line: Get paid to fix real issues on Algora, Gitcoin, IssueHunt.
- Steps: Create accounts; filter by your stack + "good first issue"; fork, fix, PR referencing bounty; claim payout after merge.
- Risk: Low.
- Best for: Builder.
- Honor: Only claim bounties you actually complete; don't game PRs.

## 3. Micro-Services on Fiverr/Upwork (effort 2, ceiling ~$200–$2,000/mo, first $ in days)
- One-line: One service you can deliver in <1 day, packaged as 3 tiers.
- Steps: Pick ONE service; create gig with basic/standard/premium; deliver early + over-deliver first 5 orders for reviews; raise prices after 10 five-star reviews.
- Risk: Low.
- Best for: Operator.
- Honor: Don't buy fake reviews; don't overpromise turnaround.

## 4. Digital Templates on Gumroad/Etsy (effort 2, ceiling ~$5–$200/sale passive, first $ in weeks)
- One-line: Build once, sell many (Notion templates, checklists, prompt packs).
- Steps: Find a template that sold in Quest 0; polish + add 2 bonuses; list with strong cover; drive traffic via content + communities.
- Risk: Low.
- Best for: Creator.
- Honor: Original work only; clear license terms.

## 5. Content + Affiliate (blog/YouTube/TikTok) (effort 2, ceiling ~$0–$10k+/mo, first $ in months)
- One-line: Slow start, high ceiling; earn via affiliate + sponsors.
- Steps: Pick one platform + one niche; post 2x/wk for 8 weeks before judging; add affiliate links only for tools you actually use; reinvest first earnings.
- Risk: Low.
- Best for: Creator.
- Honor: Disclose affiliates; don't shill junk.

## 6. B2B Consulting (Productized) (effort 4, ceiling ~$500–$5k+/client, first $ in weeks-months)
- One-line: Higher ticket; needs credibility + 2 case studies.
- Steps: Productize one outcome; land 2 free/cheap case studies; package as fixed-price offer with clear scope; ask happy clients for referrals.
- Risk: Medium.
- Best for: Operator.
- Honor: Scope creep kills; write contracts; refund if you miss SLA.

## 7. Security Bug Bounties (effort 5, ceiling ~$100–$50k+, first $ variable)
- One-line: High skill, high reward; responsible disclosure only.
- Steps: Learn OWASP Top 10; practice on PortSwigger/HackTheBox; start VDP (no payout) to build skill; report responsibly.
- Risk: Medium.
- Best for: Builder.
- Honor: Never exploit beyond PoC; never extort or leak.

## 8. In-Person Local Services (effort 1, ceiling ~$20–$100/hr, first $ same day)
- One-line: Tutoring, pet care, errands, tech help. Fastest cash, no skills.
- Steps: List 3 things neighbors pay for; post in local groups/Nextdoor; deliver excellently; ask for referrals; raise rates as demand grows.
- Risk: Low.
- Best for: Operator.
- Honor: Show up on time; charge fairly; don't upsell unnecessary work.

## 9. Licensing IP (royalties) (effort 4, ceiling royalties passive, first $ in months)
- One-line: License music, templates, designs for ongoing royalties.
- Steps: Create original IP; register/copyright where applicable; list on AudioJungle/Creative Market; collect royalties; reinvest.
- Risk: Medium.
- Best for: Creator.
- Honor: Original IP only; respect existing licenses.

## 10. Niche Newsletter / Podcast Sponsors (effort 3, ceiling ~$500–$5k/sponsor, first $ in months)
- One-line: Consistent weekly value; monetize via sponsors at ~1k engaged subs.
- Steps: Pick a niche you can write weekly for a year; publish consistently; grow to ~1k engaged subs; sell sponsor slots (flat rate, disclosed); keep editorial independence.
- Risk: Low.
- Best for: Creator.
- Honor: Disclose sponsors; never sell audience trust.

## Paths to avoid (with reasons)
- "Passive income" courses: you become the product; low margin, high refund risk.
- Crypto pumps / trading signals: legal + ethical risk; often scams.
- MLM / network marketing: recruitment-driven; most participants lose money.
- Dropshipping with no differentiation: race to bottom; supplier risk; thin margins.
- AI-spam content farms: platform bans, no real audience, violates honor code.
- Bought engagement (followers/likes/reviews): violates platform TOS + honor code; destroys trust.
- Reselling underpaid labor as premium: exploitative; breaks Code of Honor.
- Get-rich-quick "automation" bots: often violate ToS; account bans.

## Selection guide
- Need cash in 7 days → Local Services (#8) or Eval Gigs (#1).
- Have a skill + want leverage → Productized Service (existing) or Consulting (#6).
- Creative → Templates (#4) / Licensing (#9) / Content (#5).
- Technical → Bounties (#2) / Micro-SaaS (existing).
- Long game → Newsletter (#10) / Audience Asset (existing).
