# High-Range / Low-Effort Income Paths (executable)

Honest framing: "high income, low effort" is rare. Effort is front-loaded; payoff is leveraged. All paths below are ethical and executable solo.

## Tier (effort -> ceiling)
1. Premium Product ($99-$499/sale) — build once, sell many. Needs niche + launch.
2. Affiliate Engine (30-50% recurring) — content + SEO. Needs consistency.
3. Productized Service ($500-$2k/client) — fixed scope, fixed price. Needs 2 case studies.
4. Licensing (royalties) — IP creation, then passive. Needs original IP.
5. Audience Asset ($500-$5k/sponsor) — newsletter/podcast. Needs ~1k engaged subs.
6. Micro-SaaS (MRR) — recurring revenue. Highest effort, highest ceiling.

## Universal rules
- Pick ONE path. Run for 90 days before judging.
- Charge from day 1 (free users don't validate).
- Track: hours spent, revenue, hourly rate. Kill paths below $20/hr after 30 days.
- Never buy fake reviews, never plagiarize, never promise undeliverable results.

## Fastest to first $ (realistic)
- Productized service: 1-2 weeks if you have a skill.
- Premium product: 2-4 weeks if you have an audience or community.
- Affiliate: 1-3 months (SEO lag).
- Micro-SaaS: 1-3 months.

## Red flags (avoid)
- "Passive income" courses, crypto pumps, MLM, dropshipping with no differentiation, AI-spam content farms, bought engagement.
